# 🎓 Eğitim Teknolojileri 
Bu depo, eğitim süreçlerini daha verimli hale getirmek, verileri analiz etmek ve tekrarlayan görevleri otomatize etmek için geliştirdiğim çalışmaları içerir.

### 🛠️ Neler Var?
- **Veri Yönetimi:** Google Sheets tabanlı öğrenci takip ve raporlama sistemleri.
- **Otomasyon:** Python scriptleri ile veri çekme ve işleme süreçleri.
- **Analiz:** Eğitim performans verilerinin analizi ve görselleştirilmesi.

### 🚀 Kullanılan Teknolojiler
- **Dil:** Python
- **Kütüphaneler:** Pandas, Gspread (Google Sheets API)
- **Araçlar:** Excel, SQL, Low-Code Platformlar
